# NBExport

**NBExport** — это легковесный, быстрый и удобный CLI-инструмент для экспорта Jupyter Notebooks (`.ipynb`) в чистые Python-скрипты (`.py`). 

Главная цель инструмента — генерировать код, который идеально подходит для чтения LLM-агентами (Claude, Cursor, Copilot, Gemini и др.), сохраняя при этом метаданные, структуру ячеек, историю выполнения и длинные текстовые выводы.

## Особенности (Features)
- 🚀 **Мгновенный экспорт**: Обертка над чистым Python без тяжелых зависимостей.
- 👁 **Режим слежения (Watch Mode)**: Настройте `nbwatch` и забудьте о ручном экспорте. Скрипт будет автоматически генерировать `.py` файл при каждом нажатии `Ctrl+S` в Jupyter (поддерживается автосохранение `onFocusChange`).
- 🤖 **LLM-Friendly**: Экспортированные файлы имеют чистое форматирование (без "мусорных" JSON структур). Каждая ячейка явно размечена.
- 📦 **Умное извлечение Assets**: Графики (PNG) и слишком длинные текстовые выводы (более 100 строк) выносятся в отдельную папку `*_exported_assets`, чтобы не засорять код, но оставаться доступными для анализа.
- ⏱ **Execution Time**: Автоматическое извлечение и расчет времени выполнения ячеек из метаданных (VS Code, ExecuteTime, iopub).
- 🧹 **ANSI Cleaner**: Очистка выводов с ошибками от цветовых кодов консоли для удобного чтения.

## Установка

Инструмент устанавливается глобально через `pip`:

```bash
git clone https://github.com/Alexander8841/nbexport.git
cd nbexport
pip install -e .
```
*(После этого в вашем терминале станут доступны команды `nbexport` и `nbwatch` из любой папки).*

## Использование

### 1. Разовый экспорт

Перейдите в папку с вашими ноутбуками и просто введите:
```bash
nbexport
```
Скрипт найдет все `.ipynb` файлы в этой папке и сгенерирует для них `*_exported.py`.

Экспорт конкретного файла:
```bash
nbexport -i data_analysis.ipynb
```

### 2. Фоновый режим (Watch Mode)

Чтобы автоматически экспортировать ноутбуки во время работы, запустите:
```bash
nbwatch
```
Скрипт зависнет в фоне. Как только вы сохраните любой `.ipynb` файл в этой папке, инструмент мгновенно сгенерирует свежую `.py` версию (используется *debounce* для защиты от двойных срабатываний при автосохранении).

## Пример сгенерированного файла
В начале файла генерируется удобная сводка и оглавление:

```python
# --- Notebook: model.ipynb ---
# Exported: 2026-07-16 12:00:00
# SHA256:   d8e8fca2dc0f896fd7cb4cb0031ba249
# Cells:    15 (Markdown: 5, Code: 10)

# --- CONTENTS ---
# Cell 1   Markdown   1. Загрузка данных
# Cell 2   Code       import pandas as pd
...

# %% [Cell 2 | Code]
# Execution time: 0.45 sec
import pandas as pd
df = pd.read_csv('data.csv')
df.head()

# --- OUTPUT (execute_result) ---
#    id  value
# 0   1     10
# 1   2     20
```
